# TorneoFutbol

Proyecto desarrollado en Java para la gestión y simulación de un torneo de fútbol.

Permite administrar equipos, jugadores, entrenadores, estadios, fechas y partidos. También incluye funcionalidades para consultar la tabla de posiciones y gestionar la liquidación de salarios.

El proyecto aplica conceptos de programación orientada a objetos, como clases, herencia, encapsulamiento y relaciones entre objetos.

## Tecnologías utilizadas

- **Lenguaje:** Java 23.0.2
- **Entorno de desarrollo:** Apache NetBeans IDE 24
- **Sistema operativo:** Windows 11

## Ejecución

Abrir el proyecto en Apache NetBeans IDE 24 y ejecutar la clase `Main`.
